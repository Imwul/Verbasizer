작업 노트

1995년 데이비드 보위와 타이 로버츠가 가사를 쓰려고 만든 컷업 프로그램 Verbasizer를 한국어로 옮겼습니다. 노트는 이 브라우저에 저장되니, 가끔 백업을 저장해 두세요.

원문

켜 둔 칸에 글을 넣어야 섞을 수 있어요.

자를 단위

한 문장 안에서 이어지는 짧은 구절을 섞어요.

음절

비우면 모든 조각을 씁니다(줄이 길어져요).
칸 비중

켜면 칸 머리에 1~5 비중이 생겨, 긴 글이 짧은 글을 덮지 않아요.

쉼표로 나눠요. 원문에 있는 말이면 그 말이 든 조각을 먼저 뽑아요.

이 말이 든 조각은 쓰지 않아요.
⌘/Ctrl+Enter

섞은 글

0 끔
  1. 끔
  2. 부호
  3. 어순
  4. 맺음
  5. 복원

섞은 그대로 둡니다.

표시

    원문을 넣고 [잘라 섞기]를 누르면 여기에 결과가 나옵니다.

    줄을 누르면 다시 섞기·잠그기·편집·모으기 메뉴가 열립니다. 줄에 초점을 두고 R L E C 키로도 할 수 있어요.

    모은 줄

    섞은 줄을 열고 [줄 모으기]를 누르면 여기에 쌓입니다.

      예나 낭만주의 예문

      칸마다 넣을 예문을 고르세요. ‘바꾸지 않음’인 칸은 그대로 둡니다.

      후보 3개 비교
      !

      단축키

      ⌘/Ctrl+Enter잘라 섞기
      ⌘/Ctrl+Z실행 취소 (글 입력 칸 밖에서)
      ⇧+⌘/Ctrl+Z다시 실행
      ↑ ↓결과 줄 사이 이동
      R초점 둔 줄만 다시 섞기
      L줄 잠그기 / 풀기
      C줄 모으기
      E줄 편집
      S줄 소리 내어 읽기
      ?이 도움말

      작업 순서

      1. 원문 칸(최대 6개)에 글을 넣고, 쓰지 않을 칸은 체크를 끕니다.
      2. [잘라 섞기]로 줄을 만들고, 마음에 드는 줄은 잠근 채 나머지를 다시 섞습니다.
      3. 줄을 열어 조각을 고르면 그 조각만 바꾸거나, 원래 문장을 볼 수 있어요.
      4. 건진 줄은 [줄 모으기]로 모으고, 모은 줄을 다시 원문 칸에 넣어 한 번 더 섞을 수도 있어요.
      5. 노트는 브라우저에 저장됩니다. [백업 저장]으로 파일을 받아 두세요.
